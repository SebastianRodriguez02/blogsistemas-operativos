Fundamentos

💻 ¿Qué es un sistema operativo y qué tipos existen?

Para responder a la pregunta de ¿Qué es un sistema operativo?, debemos entenderlo como el programa más fundamental de una computadora. Según Tanenbaum (2009), actúa en dos frentes: como una máquina extendida que oculta la verdad del hardware complejo y como un administrador de recursos que ordena el caos de múltiples programas compitiendo por la CPU, la memoria y los discos.

¿Qué tipos de sistemas operativos existen?

La historia y evolución del hardware nos ha dejado una variedad enorme de sistemas operativos para mejorar distintas necesidades:

  • SO de Mainframes: Diseñados para procesar grandes lotes de datos y transacciones masivas.
  • SO de Servidores: Sistemas operativos como Linux y Windows Server, que operan a través de redes.
  • SO de Ordenadores Personales: El enfoque aquí es la interfaz de usuario y la comodidad (Windows, macOS).
  • SO de Nodos Sensores: Sistemas diminutos para dispositivos de internet de las cosas (IoT).

🤖 ¿Qué es un Sistema Operativo no convencional?

Un sistema operativo no convencional, son aquellos que no interactúan directamente con un usuario humano a través de una pantalla y teclado típicos, sino que están inmersos en dispositivos especializados con recursos limitados o con exigencias críticas de tiempo.

Los más destacados son los Sistemas Operativos de Tiempo Real (RTOS). A diferencia de tu ordenador personal, en un RTOS el tiempo es cuestión de vida o muerte. Se usan en marcapasos médicos, sistemas de frenado ABS en vehículos y en plataformas de robótica móvil. En estos sistemas, cumplir con una restricción de tiempo es tan importante como dar el resultado correcto.

Estructura Interna

🏗️ ¿Qué es la arquitectura de un Sistema Operativo y sus componentes?

La arquitectura de un sistema operativo es la estructura interna y la organización lógica del software que controla la máquina. Es el diseño de cómo las distintas piezas de código se ensamblan y se comunican entre sí para operar de manera segura.

¿Cuáles son los componentes de una arquitectura de un sistema operativo?

Ladrón (2018) y Serna & Allende (2020) exponen que la base arquitectónica se divide fundamentalmente en:

  • Gestor de Procesos: Encargado de la creación, planificación y destrucción de los procesos.
  • Gestor de Memoria: Asigna el espacio en RAM para que los programas puedan ejecutarse.
  • Gestor de Entrada/Salida: Maneja los drivers y controladores de hardware.
  • Gestor de Archivos (El caso Linux): Abstrae los datos físicos en discos. En sistemas como Linux, "todo es un archivo".

🧩 ¿Qué tipos de arquitectura existen?

La forma en que se estructuran los componentes mencionados anteriormente define el diseño central del núcleo (kernel). Existen varios tipos de arquitectura:

  • Arquitectura Monolítica: Todo el sistema operativo es un solo programa binario enorme que se ejecuta en modo núcleo. Linux es el ejemplo clásico. Es increíblemente rápido, pero un fallo en un componente menor puede tumbar todo el sistema.
  • Microkernel (Micronúcleo): Divide el sistema en pequeños módulos. Solo lo estrictamente necesario corre en modo núcleo, mientras que el resto de componentes operan en modo usuario. Es altamente confiable y seguro.
  • Arquitectura Cliente-Servidor: Una variación del microkernel donde las aplicaciones funcionan como clientes que solicitan servicios a procesos servidores.

Ejecución

⚡ ¿Qué es un proceso en sistemas operativos?

Un proceso en sistemas operativos, la definición clásica según Cura (2020) es que un proceso es un "programa en ejecución". Mientras que un programa es solo un archivo en tu disco duro (entidad pasiva), un proceso es una entidad activa. Posee un hilo de ejecución, un contador de programa, registros y variables en memoria.

Estados de un proceso

Dado que la CPU alterna rápidamente entre ellos para generar la ilusión de multitarea, los procesos transitan por tres estados fundamentales:

  1. En ejecución (Running): Usando la CPU en ese milisegundo exacto.
  2. Listo (Ready): Preparado para ejecutarse, esperando que el planificador le asigne tiempo.
  3. Bloqueado (Blocked): Pausado temporalmente hasta que ocurra un evento externo, como la lectura de un archivo.

Ejecución

⚠️ ¿Qué tipos de procesos existen, cuáles son sus características y qué problemas presentan?

Lo procesos podemos clasificarlos según su comportamiento:

  • Limitados por CPU (CPU-bound): Consumen todo su tiempo haciendo cálculos matemáticos pesados.
  • Limitados por E/S (I/O-bound): Pasan la mayor parte del tiempo en estado "bloqueado" esperando que el disco duro o la red respondan.

Que problemas presentan

Cuando los procesos intentan colaborar o compartir recursos, se enfrentan a graves problemas descritos por Tanenbaum (2009):

  • Condición de carrera (Race Condition): Ocurre cuando dos procesos acceden a una memoria compartida al mismo tiempo. El resultado final se vuelve impredecible.
  • Interbloqueo (Deadlock): Ocurre cuando el Proceso A tiene el recurso 1 y espera el 2, pero el Proceso B tiene el recurso 2 y espera el 1. Ambos se quedan esperando eternamente.

Optimización

🧠 ¿Qué es un algoritmo de planificación?

En un sistema multitarea moderno, frecuentemente hay decenas de procesos en estado "Listo", pero solo un procesador para atenderlos.

Un algoritmo de planificación es el conjunto de reglas y lógica matemática que utiliza el componente del sistema operativo llamado planificador para decidir qué proceso debe ejecutarse a continuación y por cuánto tiempo. Su objetivo principal es maximizar la equidad, mantener la CPU ocupada el 100% del tiempo y minimizar el tiempo de espera del usuario.

⚙️ ¿Existen tipos de algoritmos de planificación?

Absolutamente. Respondiendo a ¿Existen tipos de algoritmos de planificación?, la respuesta depende del entorno del sistema operativo. Cura (2020) detalla los más importantes:

  • Planificación no apropiativa: Una vez que se le da la CPU a un proceso, este no se le puede quitar hasta que termine o se bloquee voluntariamente.
    • First-Come, First-Served (FCFS): El primero en llegar a la cola es el primero en ser atendido.
    • Shortest Job First (SJF): Ejecuta primero el proceso que requiere menos tiempo de CPU.
  • Planificación apropiativa (Preemptive): El SO tiene el poder de suspender un proceso a la fuerza.
    • Round Robin: El más usado. A cada proceso se le da un intervalo de tiempo fijo (quantum). Si no termina en ese tiempo, la CPU pasa al siguiente en la fila.
    • Planificación por Prioridad: Los procesos se agrupan por jerarquía. Los procesos del sistema tienen prioridad sobre los procesos del usuario común.
