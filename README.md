# Entre procesos — Blog de sistemas operativos

Proyecto estático desarrollado con HTML, CSS y JavaScript, sin frameworks ni dependencias de compilación.

## Cómo abrirlo
1. Descarga y descomprime la carpeta.
2. Abre la carpeta `blog-sistemas-operativos` en Visual Studio Code.
3. Abre `index.html` en el navegador. También puedes usar la extensión Live Server.
4. Edita los textos de las entradas en `js/main.js` y los estilos en `css/styles.css`.

## Publicación
Puedes subir el contenido a un repositorio de GitHub y conectarlo a GitHub Pages, Netlify o Vercel. Al ser una web estática, no requiere servidor backend.

## Estructura
- `index.html`: estructura y secciones principales.
- `css/styles.css`: estilos y diseño adaptable.
- `js/main.js`: contenido de las diez entradas, filtros, ventana de lectura y simulador FCFS/Round Robin.
- `assets/images/`: carpeta para imágenes que decidas incorporar.

## Antes de entregar
- Revisa los textos y ajusta ejemplos o expresiones a tu forma de escribir.
- Comprueba los datos bibliográficos de las lecturas de Cura y Ladrón con el material de tu universidad.
- Añade tu nombre, asignatura, docente y fecha en el documento Word que acompañará el enlace.
- Prueba el enlace publicado desde una ventana privada o desde otro dispositivo.
